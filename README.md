# CPU Scheduling Algorithms

A C# Windows Forms project demonstrating fundamental CPU scheduling algorithms: First Come First Serve (FCFS) and Round Robin (RR).

## Features

- User registration and login
- Process input with arrival time, burst time, and process ID
- FCFS scheduling
- Round Robin scheduling with configurable time quantum
- Completion time, turnaround time, and waiting time calculations
- Average scheduling metrics
- Gantt chart visualization and calculation breakdowns in the Pro workflow

## Technology

C#, Windows Forms, and SQL Server.

## Purpose

The project provides a practical visual way to study CPU scheduling algorithms and their calculated performance metrics.
